  broad "追加 in t" → modify_score to prevent miscouting.

Every test checks revealed_cards state (the discriminant). No test checks
waitroom state directly (cards start in waitroom from setup, so contains()
is always true regardless of whether the move happened).

revealed_cards, which may also move the unselected card. Tests only assert
about the SELECTED card leaving revealed_cards.
