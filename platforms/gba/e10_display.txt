    GBA display: sprite-based refactor
    
    - Replace 7 RegularBackground layers with 1 text_bg + sprites
    - Card art now uses Object sprites (DynamicSprite256) instead of 8bpp backgrounds
    - Single PaletteVramMulti with MASTER_PAL shared by all card sprites
    - No manual VRAM clearing - agb manages sprite VRAM via SpriteVram ref-counting
    - create_card_sprite helper builds sprites on-demand per card/size
    - render_board_frame, render_action_text, render_card_detail, swap_buffers all use sprites
    - Removed draw_slot (tile-based) and reset_vram (no longer needed)
    
    ROM builds: output/rabuka_gba.gba
