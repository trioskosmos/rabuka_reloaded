# Plan: Eliminate Duplicate Assets & Build WebP Compression Benchmark

## Goal
1. Stop duplicating image and other asset folders across `web_ui/`, `cards/`, and `dist/`.
2. Create a compression benchmark folder (e.g., `img/cards_webp_compression_test/`) with `PL!SP-bp5-222-P2.webp` encoded at various quality levels, to visually/numerically assess minimum viable size.

---

## Current State

**Vite build** (`web_ui/vite.config.js`) copies asset directories into `web_ui/dist/` on every build via a `copy-assets` plugin (`closeBundle` hook):
- `js/i18n` → `dist/js/i18n`
- `img` → `dist/img`
- `decks` → `dist/decks`
- `../cards` → `dist/cards`
- `js/card_image_mapping.json`, `deck_converter.html`

**Card images** (~800+ files in `web_ui/img/cards_webp/`):
- Referenced via `img/cards_webp/${cardNo}.webp` in `js/components/CardRenderer.js:117,159`
- DevMiddleware already serves files from repo root (`web_ui/../cards`, `web_ui/..`) via custom handler.

**Duplication risk**: If any launcher/bundler also copies these folders independently, we get redundant copies.

---

## Proposed Changes

### 1. Single-source-of-truth for static assets

- Remove the `copy-assets` plugin entirely from `vite.config.js`.
- Use **Vite `publicDir`** instead (designated folder served directly and copied verbatim to `dist/`):
  - Set `publicDir: 'static'`
  - Move `cards`, `img`, `decks`, `i18n`, `card_image_mapping.json`, `deck_converter.html` into `web_ui/static/` preserving relative paths.
- Adjust dev middleware paths to point to `static/` folder instead of `..`.

### 2. Vite dev-middleware path fix

Update `configureServer` snippet:
```js
if (req.url?.startsWith('/cards/') || req.url?.startsWith('/img/') || req.url?.startsWith('/decks/') || req.url?.startsWith('/engine/')) {
  const filePath = resolve(__dirname, 'static', req.url);
  ...
}
```

### 3. Compression benchmark script

Add `scripts/bench_webp.py` (Python, Pillow or cwebp):

- Input: `web_ui/img/cards_webp/PL!SP-bp5-222-P2.webp` (or the first available sample user pointed out)
- Outputs into `web_ui/img/cards_webp_bench/` at these quality/effort presets:

| Label | Quality | Effort/Method | Expected size vs original |
|---|---|---|---|
| `lossless` | lossless | webp lossless | ~1×–1.3× |
| `q90` | 90 | 6 | small reduction |
| `q75` | 75 | 6 | moderate reduction (~30-40%) |
| `q60` | 60 | 6 | larger reduction |
| `q40` | 40 | 4 | aggressive |
| `q20` | 20 | 4 | very aggressive |

- Prints bytes-per-image and total for each preset so we have a table for decision making.
