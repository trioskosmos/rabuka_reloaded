  Trigger: 自動, trigger_type: each_time
  Condition: location_condition(stage, member, negation=true, heart_type=all)
  Action: gain_ability(count=1, duration=live_end)

>> ISSUE 1: The raw text says '自分のステージにいるメンバーのライブ開始時能力が解決するたび'
   (each time a member's live_start ability resolves)
   This is a 'watching' trigger - it triggers when OTHER cards' abilities resolve.
   The parsed entry has trigger_type=each_time but does NOT capture the sub-trigger
   condition that it only fires when 'live_start' abilities resolve. This means the
   engine might trigger on ANY auto ability resolving, not just live_start abilities.

>> ISSUE 2: QA Q217 and Q227 clarify that this ability ONLY triggers if cost WAS PAID
   for the triggering live_start ability. This 'cost_paid' dependency is NOT captured
   anywhere in the parsed condition/effect.
   Q227: 'コストの支払いが必要な能力に対してコストを支払いませんでした。このとき、このカードの能力は発動しますか？ → いいえ'

--- PARSED ab#1 (uab#543) ---
  Action: sequential [do_nothing, draw_card]

>> CRITICAL BUG: Effect[0] is 'do_nothing' with empty text!
   This is a parser artifact. The raw text says simply 'カードを1枚引く' (draw 1 card).
   There is NO reason for a do_nothing action before draw_card.
   The parsed output should just be {action: draw_card, count: 1, ...}
   This 'do_nothing' wasteland will cause the engine to waste an action step doing nothing.

   [1] modify_score (score+1) and [2] gain_ability
   These should be a SINGLE action: 'gain an ability that does modify_score'.
   As parsed, the engine would add +1 to score immediately AND gain a separate
   ability that does... nothing (since the score mod was already applied).

====================================================================================================
SUMMARY OF CRITICAL PARSER BUGS FOUND
====================================================================================================

CRITICAL (affects gameplay):
  1. Dazzling Game ab#0: FIRST MEMBER SELECTION ENTIRELY MISSING
     The parser skipped selecting from {かのん, マルガレーテ, 冬毬} entirely.
  2. MIRACLE WAVE: FIRST OR-CONDITION DROPPED
     The '0 cards without blade heart' condition is not parsed.
  3. 繚乱！ビクトリーロード ab#1: SPURIOUS do_nothing ACTION
     Empty 'do_nothing' action before draw_card wastes an action step.
  4. 桜内梨子: CONDITIONAL BRANCH NOT CAPTURED
     'そうしなかった場合' (if [opponent] did not discard) logic is missing.
  5. 高坂穂乃果: SELECT ACTION MISSES live_card OPTION
     Only member_card (cost_limit=10) is parsed, live_card option dropped.

MODERATE (affects correctness):
  6. 葉月恋 ab#1: WRONG SOURCE in move_cards
     Should be 'discard' not 'revealed_cards' for the card recovery.
  7. 桜内梨子: SPLIT modify_score + gain_ability
     Should be one 'gain ability' action, not separate score mod + ability gain.
  8. 矢澤にこ ab#0: MISSING blade count filter
     '元々持つブレードが1つ以下' condition not in target filter.
  9. 繚乱！ビクトリーロード ab#0: MISSING sub-trigger scope
     Should only fire when 'live_start' abilities resolve, not all auto abilities.
  10. AWOKE: Condition scope ambiguity - current yell vs all revealed cards.

LOW (edge cases / parser quality):
  11. 高坂穂乃果: 'reveal until found' pattern parsed as nested sequential+select
     instead of a dedicated 'reveal_until' action type.
  12. 葉月恋 ab#1: Optional E payment as 'custom' instead of proper optional cost.
