UI Mode: View vs Play

The top-right button toggles between View and Play mode:

  • View — Browse the board, inspect cards, read abilities. Click any card to see its detail. No actions are taken.
  • Play — Interact with the game: play cards from hand, activate abilities, set live cards, select targets. Valid targets are highlighted in green.

Import from Deck Log

  1. Go to decklog.bushiroad.com, find a deck, and open its detail page.
  2. Open DevTools (usually F12) and do as the picture shows.
  3. In the game setup modal, select "Paste Deck List" and paste the HTML into the text area.
  4. Can also use an extension like https://chromewebstore.google.com/detail/copy-html/indfogjkdbmkihaohndcnkoaheopbhjf

Tip: You can also paste plain text like "PL!-bp3-012-RM x 3" or "3 x PL!-bp3-012-RM".

📱 Mobile

  • Use the Menu button (bottom-right) to toggle the sidebar.
  • Zones like hand and stage are horizontally scrollable.

🎮 Controls

  • Update: Re-fetches the game state.
  • Reset: Restarts the game from the beginning.
  • Click a card to use or move it.
