## How to read this

Three coverage levels — they answer different questions:

| Level | Question | Meaning |
|---|---|---|
| **Card (L0)** | Is this card's `card_no` referenced in any test? | A test `game.id("PL!N-bp7-011-R+")` shows up. Does NOT prove firing. |
| **Fires (L1/L2)** | Does a test assert the effect? | Inferred: `assert` in covering file → L1; negative-path file/test name → L2. |
| **Mechanic** | Is any test exercising this trigger / action / condition? | Even if a specific card is untested, a shared `action`+`condition` still covers the engine path. |

`depth` is auto-inferred (see `cards/test_inventory.py:depth`); add `/// @covers PL!X-... depth=L2` to override. Details: `engine/tests/TEST_INVENTORY.json` / `.md`, matrix: `docs/ABILITY_MATRIX.md`.

A card with multiple abilities counts as **covered** if *any* is touched; check gap list for finer detail.
