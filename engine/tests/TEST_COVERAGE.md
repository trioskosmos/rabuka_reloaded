## How to read this

Two coverage levels — they answer different questions:

| Level | Question | Meaning |
|---|---|---|
| **Card** | Is this card's `card_no` referenced in any test? | A test `game.id("PL!N-bp7-011-R+")` shows up in the suite. Does NOT prove every ability on that card is exercised. |
| **Mechanic** | Is any test exercising this trigger / action / condition? | Even if a specific card is untested, another card sharing the same `action`+`condition` still covers that engine path. |

A card with multiple abilities counts as **covered** if *any* of them is touched; check the per-ability gap list for finer detail.
